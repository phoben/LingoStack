# V1 桌面集成与结果操作

## Goal

让 Windows 用户从任意应用划词到主窗口翻译、托盘导航、复制/收藏/朗读/停止形成可观察、可恢复的完整桌面闭环。

## Dependencies

- 依赖 `08-14-v1-translation-intelligence` 的翻译/词条结果契约。
- 依赖 `08-14-v1-settings-localization-hotkeys` 的路由、本地化与热键状态契约。

## Requirements

- `Ctrl+Shift+D` 唤起主窗口、切换翻译页、读取选区并自动翻译；不创建第二窗口。
- UIA 成功、剪贴板降级与最终失败均有不同且可理解的 UI 反馈；失败后允许手动粘贴。
- 托盘含打开主窗口、划词翻译、收藏、设置、退出，并把已有窗口聚焦到目标视图。
- 翻译结果复制、收藏、朗读可用；TTS 可停止，失败/Unsupported 可见。
- 收藏继续支持扁平持久化、搜索、JSON 导入/导出、删除与朗读；无效导入不破坏数据。
- 保持单实例，第二次启动只聚焦现有主窗口。

## Acceptance Criteria

- [ ] Windows 任意应用选中文本并按热键后，主窗口聚焦且自动翻译对应文本。
- [ ] 剪贴板降级显示非阻塞提示；完全失败显示操作建议，现有输入不被无提示清空。
- [ ] 托盘五项动作路由正确，关闭/隐藏后仍可重新打开；第二实例不产生第二个窗口。
- [ ] 朗读按钮可切换为停止；快速连续朗读不重叠，错误和未支持状态可被读屏识别。
- [ ] 翻译收藏后可在收藏页检索、导出、重新导入和朗读；损坏 JSON 不改变现有列表。
- [ ] Windows 手工验证记录区分实际 UIA/SAPI 证据与自动化事件/IPC 证据。

## Out of Scope

- 自动监听选区、PopClip 工具栏、翻译浮窗。
- macOS/Linux 原生 selection/TTS 实现。
- 收藏分组/标签和云同步。
