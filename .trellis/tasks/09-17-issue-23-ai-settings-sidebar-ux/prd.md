# 实施 Issue 23 AI 配置与侧栏体验优化

## 目标

让尚未完成 AI 模型配置的用户能够从翻译相关失败位置直接进入“设置 → AI”，同时修正侧栏文字过早消失/过晚恢复的问题，并允许用户在编辑提供商时临时查看 API Key。

## 背景与已确认事实

- GitHub Issue #23 已标记 `ready-for-agent`，其 triage 结论是本任务只覆盖 AI 配置缺失引导、侧栏文字显示边界和 API Key 临时显隐。
- 内置提供商预设、远程模型发现、模型多选、新协议和模型参数已拆分到 Issue #24，不属于本任务。
- AI 模型解析的既有业务规则是“功能默认模型 → 全局默认模型 → 校验提供商存在”（`crates/lingostack-core/src/config.rs:147`）。
- 翻译与命名当前把全部失败视为普通请求错误，只显示“重试”（`src/components/views/translate-view.tsx:336`、`src/components/views/naming-view.tsx:139`）。文档和收藏也只提供重试入口（`src/components/views/docs-view.tsx:459`、`src/components/views/favorites-view.tsx:99`）。
- 设置页当前只能导航到页面级 `settings`，AI 子页由组件本地状态控制（`src/stores/app-store.ts:15`、`src/components/views/settings-view.tsx:93`）。
- 侧栏当前使用固定 `132px` 阈值，不考虑当前界面语言的真实菜单宽度（`src/lib/sidebar-layout.ts:17`、`src/components/sidebar.tsx:32`）。
- API Key 输入框始终为 `password`，没有临时查看入口（`src/components/provider-form.tsx:98`）。

## 需求

### R1：AI 配置缺失引导

- 翻译、命名、词条解释和文档翻译必须采用同一条 AI 可执行性判定规则。
- 功能未分配模型且无全局默认模型，或模型引用的提供商已不存在时，视为 AI 配置缺失。
- 用户在上述配置缺失状态下尝试执行功能后，错误区域必须显示“设置 AI”，不显示无效的“重试”。
- 点击“设置 AI”必须直接进入“设置 → AI”，不能只进入设置首页。
- 网络异常、限流、提供商服务异常以及其他非配置错误继续显示“重试”。
- 配置缺失判定不改变现有模型配置持久化结构，也不解析后端错误文案。

### R2：侧栏文字显示边界

- 是否显示菜单文字必须根据当前界面语言下最长菜单项的真实占用宽度决定，不再依赖固定阈值。
- 宽度足够完整容纳图标、间距、文字和既有内边距时显示全部文字；否则统一切换为纯图标。
- 缩窄与拉宽必须使用同一边界，不得出现迟滞区间。
- 菜单文字不得先被截断再切换为纯图标。
- 拖拽、键盘调宽、双击折叠、宽度持久化及无障碍名称继续有效。

### R3：API Key 临时显隐

- 提供商表单中的 API Key 默认掩码显示。
- 输入框右侧提供带眼睛图标的按钮，可在当前表单会话内切换明文/掩码。
- 眼睛按钮必须有本地化的无障碍名称、键盘焦点和当前状态反馈。
- 保存、取消、关闭或重新打开表单后必须恢复为掩码。
- 显隐状态不得写入配置、浏览器存储或日志。

## 验收标准

- [ ] 翻译、命名、词条解释和文档翻译因 AI 配置缺失而无法执行时，均显示“设置 AI”。
- [ ] 点击任一“设置 AI”后直接进入“设置 → AI”。
- [ ] AI 配置缺失时不再显示无效的“重试”。
- [ ] 网络、限流和提供商服务异常等临时故障仍显示“重试”。
- [ ] 功能专用模型为空但全局默认模型有效时，功能仍被视为可执行。
- [ ] 模型引用已删除的提供商时，被识别为配置缺失。
- [ ] 中文和英文菜单文字在能够完整容纳时保持显示。
- [ ] 菜单文字不会先被截断再切换为纯图标。
- [ ] 缩窄和拉宽采用同一文字显示边界。
- [ ] 拖拽、键盘、双击和持久化侧栏宽度行为无回归。
- [ ] 每次打开新增或编辑提供商表单时，API Key 均默认掩码显示。
- [ ] 眼睛按钮只切换当前表单会话中的明文或掩码状态。
- [ ] 保存、取消或重新打开表单后恢复为掩码。
- [ ] 自动化测试覆盖三组行为及其关键边界。
- [ ] `pnpm lint`、`pnpm test`、`pnpm build` 通过。

## 范围外

- 内置提供商预设、提供商 tag、远程模型列表刷新、模型多选和输入框/下拉框切换（Issue #24）。
- 新增 LLM 协议、模型参数或模型配置迁移。
- 修改 API Key 的持久化或密钥存储架构。
- 重新设计网络、限流或提供商服务异常的处理方式。
- 新增独立侧栏折叠按钮或重做主窗口导航视觉。
- 修改 Rust IPC 错误协议；本任务使用已加载的前端配置做确定性预检。
