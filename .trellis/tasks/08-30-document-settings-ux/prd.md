# 优化文档翻译与设置界面

## Goal

让文档翻译操作准确反映“一次整篇请求”的真实能力，并统一设置页的模型继承语义与紧凑布局，减少错误预期和无效高度占用。

## Background

- 当前文档翻译一次提交整篇规范化 Markdown，成功后才原子保存完整译文（`.trellis/tasks/08-30-document-translation/prd.md:29-34`、`src-tauri/src/commands.rs:242-297`）。
- 当前“暂停”和“取消”都会阻止在途结果落库并把记录置为内部 `paused` 状态；再次开始会重新提交整篇文档，不能从响应中断点继续（`src-tauri/src/commands.rs:205-239`、`crates/lingostack-document/src/lib.rs:139-167`）。
- 模型配置已经支持 `translate`、`naming`、`doc_translate` 空值回退到 `global_default`；当前只有文档选择器把空值文案显示为“使用全局默认模型”（`crates/lingostack-core/src/config.rs:260-274`、`src/components/settings-ai.tsx:195-228`）。
- 外观页的 Prompt“恢复内置”按钮目前位于输入框下方独占一行；无说明文字的 `SetSection` 标题与子内容之间没有间距（`src/components/views/settings-view.tsx:35-46,353-428`）。
- 相关文档翻译任务仍保留“暂停/继续”的旧验收表述；本需求批准后以本任务的“取消/重试”用户语义为准。

## Requirements

### R1. 文档任务只呈现真实可执行的操作

- 文档处于翻译中时，工具栏只显示“取消”，不显示“暂停”。
- 取消后不得向用户显示“暂停”或“继续”；内部 `paused` / `pausing` 兼容状态统一呈现为“已取消”，并提供“重试”。
- “重试”重新发起整篇翻译，不承诺从取消位置继续；失败态仍提供“重试”，完成态仍提供“重新翻译”。
- 后端暂停命令、数据库兼容状态、启动恢复和迟到结果守卫保持不变，本任务不做 schema 迁移。

### R2. 功能默认模型统一继承语义

- 翻译、命名、文档三个功能模型选择器的空选项都显示“使用全局默认模型”及其英文文案。
- 全局默认模型自身的空选项继续显示“未指定 / Unassigned”，避免形成循环继承含义。
- 选择具体模型、清空功能分配、删除提供商后的引用清理继续写入现有字段并自动保存，不新增配置字段或解析规则。

### R3. Prompt 恢复操作压缩为同一标题行

- 每个 Prompt 的业务 Label 与“恢复内置”按钮处于同一行，输入框位于下一行。
- 按钮不再单独占据一行；现有 Label/Input 关联、键盘操作和保存行为保持有效。

### R4. 主题标题与选择器保持可见间距

- “主题”标题与下方单选选择器组之间使用现有 4px 网格中的一致间距，不再视觉粘连。
- 不改变主题选项、持久化键、主题切换行为或现有视觉令牌。

### R5. 本地化、可访问性与任务一致性

- 新增或调整的状态、操作和模型继承文案同时覆盖中文与英文。
- 控件继续使用真实 button/radio/select/label 语义和可见焦点；不以纯样式元素代替交互控件。
- 最小化同步仍在进行的文档翻译任务中与“暂停/继续”冲突的需求与验收文字，避免两个活动任务互相矛盾。

### R6. 文档阅读器原文优先

- 文档页的阅读模式顺序固定为“原文 / 译文”，首次进入默认选中并显示原文。
- 键盘 Home/左方向键选择原文，End/右方向键选择译文；文件右键菜单使用相同顺序。
- 用户手动切到译文后，只有完整译文可进入 reader；翻译中或部分失败的内部片段仍不得泄露。

## Acceptance Criteria

- [x] AC1：翻译中的文档只显示“取消”，页面中不存在“暂停”操作。
- [x] AC2：取消后的兼容状态显示“已取消”，只提供“重试”；界面不宣称可“继续”，重试会重新发起整篇翻译。
- [x] AC3：翻译、命名、文档三个选择器均可清空为“使用全局默认模型”；全局默认行清空时仍为“未指定”。
- [x] AC4：三类功能模型的选择、清空及提供商删除清理继续通过 `saveConfig` 持久化现有配置结构。
- [x] AC5：每个 Prompt 的 Label 与“恢复内置”按钮同一行，输入框位于其下；恢复按钮仍将对应 override 清空。
- [x] AC6：“主题”标题与单选选择器之间存在一致的可见间距，中文/英文主题名称与 radio 语义不回退。
- [x] AC7：相关 RTL 覆盖取消/重试语义、三类模型回退文案、Prompt 标题行与主题间距结构；前端 lint、test、build 通过。
- [x] AC8：在可用的本地 Tauri 运行时按 1080×720 和 864×576 检查外观页高度利用和控件无重叠；若运行时不可用，明确记录未执行，不能以 RTL 冒充视觉验收。
- [x] AC9：文档页按“原文 / 译文”排列并默认显示原文；键盘与右键菜单顺序一致，手动切到未完成译文时不显示源片段或内部占位。

## Out of Scope

- 为 LLM 流新增真正的暂停、续传或断点恢复协议。
- 删除 Rust `pause_document`、内部 `paused` / `pausing` 状态、历史数据库字段或兼容读取逻辑。
- 重构整个设置页、提供商 CRUD、主题 store 或配置 schema。
- 修改文档翻译结果、Prompt 协议、Markdown reader 或导入能力。
- 提交、推送、部署或归档其他活动任务。

- 本任务主要影响 `docs-view.tsx`、`document-store.ts`、`settings-ai.tsx`、`settings-view.tsx`、`i18n.ts` 及对应测试；预计不改变 Rust/TS IPC 数据形状。
