# V1 设置、本地化与热键

## Goal

把当前设置原型变为真实、可持久化且可修复的配置体验，使用户能用中文或英文管理语言规则、Prompt、主题、模型与全局热键。

## Dependencies

- 依赖 `08-14-v1-translation-intelligence` 已稳定语言/Prompt 与 IPC 契约。

## Requirements

- 多提供商 CRUD、功能默认模型和全局模型继续可用；融合解释不再显示独立 Explain 模型入口。
- 支持语言映射增删、全局默认目标和 `system | zh | en` 界面语言；下一次翻译立即使用保存结果。
- 中英文覆盖 V1 所有实际主窗口视图、导航、操作、状态、错误和设置文案；文档占位内容可保持非业务占位，但导航名称必须本地化。
- Prompt 设置支持翻译/命名覆盖、恢复内置，并明确固定词条协议不可覆盖。
- 主题以 Rust 配置为持久化真源，localStorage 只做同步的首屏防闪烁缓存。
- 热键页展示实际绑定与注册状态，支持键盘组合捕获、合法性校验、保存、重新注册和冲突修复。
- V1 只保留划词翻译与打开主窗口两种动作；旧 `translate_popup` 配置可迁移且保存后消失。

## Acceptance Criteria

- [ ] 切换界面语言后当前窗口即时切换，重启保持；system 模式根据系统语言选择中/英并有可测 fallback。
- [ ] 增删语言映射、修改默认目标后，下一次自动目标语言解析符合规则并在重启后保持。
- [ ] 翻译/命名 Prompt 可保存、清空回退；帮助文案说明机器协议固定，配置保存错误可见。
- [ ] 主题在设置页与标题栏切换时同步写入 Rust 配置及防闪烁缓存，重启无明显错误主题闪烁。
- [ ] 热键捕获拒绝裸键/空键和同应用重复组合；系统注册失败的具体项标红，用户修改后可重新注册成功。
- [ ] 旧三热键默认配置迁移为 `Ctrl+Shift+D` 划词与 `Alt+Space` 主窗口两项，不恢复翻译浮窗。
- [ ] 设置与热键事件具备 RTL/store/Rust 迁移测试，跨 IPC 往返实测通过。

## Out of Scope

- 新增 UI 语言、在线翻译资源、社区翻译工作流。
- V2 浮窗/工具栏热键。
- Windows 之外的默认组合优化。
